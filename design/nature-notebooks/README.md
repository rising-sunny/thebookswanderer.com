# Reproducible notebook design sources

See `server/docs/NATURE_NOTEBOOKS.md` for source attribution, print dimensions,
page structure, private print-file transport and publication instructions.

These scripts place real public-domain museum reproductions unchanged into
original editorial layouts. They do not synthesize or repaint illustrations.

The 160-page paperback is printed in English. Its sample and preview images
are generated directly from the final PDF. The Printify hardcover uses the
supplier's standard 150-page lined interior; only the full-wrap cover is custom.
