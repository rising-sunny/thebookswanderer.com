# The Lost Manuscript — Case 01: The Keeper’s Letter

An original English-language reader prototype by The Books Wanderer.

Start with [the reader PDF](the-lost-manuscript-case-01.pdf). Use the
[hints](the-lost-manuscript-hints.pdf) one at a time if you get stuck.
The [solutions and epilogue](the-lost-manuscript-solutions.pdf) contain spoilers.

[Download the reader pack](the-lost-manuscript-reader-pack.zip) to get all three
PDFs and reading instructions. Use GitHub's **Download raw file** button if its
preview opens first.

The reader PDF has seven pages, the hint booklet two and the solutions three.
This is the first case of a planned six-case book. It has been checked for
logical consistency and PDF layout; it has not yet been playtested with readers.

This branch contains review files only. No storefront changes, print orders
or deployment are included.
